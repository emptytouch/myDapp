# myDapp

本仓库用于集中存放多个去中心化应用（DApp）项目。每个 DApp 通常以独立子目录形式组织，便于分别维护前端、智能合约与部署脚本。

## 仓库结构

| 目录      | 说明                         |
| --------- | ---------------------------- |
| `DApp_01` | 示例 DApp（含前端与合约等） |

后续新增的 DApp 建议统一命名为 `DApp_02`、`DApp_03` … 或在各子目录内附带各自的 `README.md` 说明技术栈与启动方式。

## 使用说明

1. 进入对应 DApp 子目录，按其文档安装依赖并运行。
2. 请勿将私钥、`.env` 中的敏感配置或体积过大的构建产物提交到本仓库（根目录 `.gitignore` 已做常见排除）。

## 许可

各子项目若单独声明许可证，以子项目为准；未声明时以仓库根目录约定为准（如有）。
